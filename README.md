E-Commerce Sales Power BI Dashboard
An interactive Power BI dashboard designed to analyze e-commerce sales performance, customer behavior, product performance, and customer segmentation.

📊 Dashboard Overview
This project contains two interactive dashboard pages:

1. Executive Overview
Provides a high-level view of business performance, including:
Total Revenue
Total Orders
Total Customers
Average Order Value
Monthly Revenue Trend
Revenue by Country
Top 10 Products by Revenue
Monthly Cancellation Orders

3. Customer & Product Insights
Provides deeper analysis of customers and products, including:
Customer Performance Overview
Customer Segment Distribution
RFM Score Distribution
Top 10 Customers by Revenue
Top 10 Products by Units Sold
Revenue by Customer Segment

🎯 Key Features
Interactive Year, Country, and Month slicers
KPI cards for key business metrics
Customer segmentation using RFM analysis
Product performance analysis
Geographic revenue analysis
Monthly sales and cancellation trends
Interactive cross-filtering between visuals

🛠️ Tools Used
Microsoft Power BI
Power Query
DAX
Data Modeling

💡 Project Goals
The goal of this project was to transform e-commerce transactional data into an interactive dashboard that supports data-driven decision-making.

The dashboard helps answer questions such as:
How is revenue changing over time?
Which countries generate the most revenue?
Which products perform best?
Who are the highest-value customers?
How are customers distributed across different RFM segments?
What are the trends in order cancellations?
